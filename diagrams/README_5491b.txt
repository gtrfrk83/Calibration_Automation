B&K Precision 5491B hook-up diagrams
====================================
The procedure shows a picture each time the wiring changes. Drop PNG files in this folder (any size; they are shown beside the instructions).
Missing pictures do not stop a run: the dialog shows the text instructions and names the file it looked for.

File name:   hook_5491B_<calibrator>_<GROUP>.png      e.g. hook_5491B_5522A_VOLT.png
Shared:      hook_5491B_<GROUP>.png                    used for every calibrator when there is no calibrator-specific file
Search order: hook_5491B_<cal>_<G>  ->  hook_5491B_<G>

<calibrator> = 5522A, 5560A or 5520A

GROUP
  VOLT   calibrator voltage to V/Ohm and COM (DC volts, AC volts, frequency, continuity); also used for the points done with your own standard
  OHM2   2-wire ohms: calibrator output to V/Ohm and COM
  IMA    calibrator current to the mA terminal and COM (DC / AC current up to 500 mA)
  I20A   calibrator current to the 20 A terminal and COM (5 A and 20 A ranges)
